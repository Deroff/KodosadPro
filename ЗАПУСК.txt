Кодосад Studio — SQL Server, Windows x64, 02.10.2026

Актуальная сборка: outputs/CourseworkBuilds/06-KodosadStudio-SqlServer-2026-10-02-LocalDbFix/KodosadStudio.exe
Запускайте EXE из его папки вместе с остальными файлами. .NET включён в сборку.

Нужен установленный SQL Server LocalDB. База находится в экземпляре (localdb)\MSSQLLocalDB.
Если экземпляр остановлен: sqllocaldb start MSSQLLocalDB
По умолчанию используется база KodosadStudioDb. При запуске схема создаётся или обновляется с сохранением существующих записей.
Другой сервер задаётся переменной KODOSAD_SQL_SERVER, другое имя базы — KODOSAD_DATABASE_NAME.
Для подтверждения регистрации, подтверждения старой почты и сброса пароля требуется запущенный RouteStudio Mail API с настроенными токеном и SMTP. Гарантировать доставку без него нельзя.
Сброс доступен только после подтверждения почты. Если аккаунт создан до миграции v3, войдите с прежним паролем → Профиль → «Подтвердить почту»: код отправляется только на уже сохранённый адрес. После этого на экране входа можно использовать «Забыли пароль?».
