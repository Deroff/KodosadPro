# Проверка Kodosad Studio

Актуальная SQL Server сборка проверена 02.10.2026. Результаты r9/r10 ниже сохранены как история предыдущих проверок.

## Сборка и модульные тесты

- `dotnet build KodosadStudio.sln -c Release --no-restore` — успешно, 0 предупреждений, 0 ошибок.
- `dotnet run --project KodosadStudio.Tests/KodosadStudio.Tests.csproj -c Release` — 33/33, включая одноразовость шестизначного кода подтверждения, контракт Mail API для сброса и запрет удалённого HTTP.
- Алгоритмический охват: круговое преобразование Хаффмана, Шеннона–Фано и RLE; пустой и односимвольный вход; Unicode и знаки пунктуации; некорректные серии RLE, выход за диапазон UTF-16 и ограничение объёма декодирования; неизвестный алгоритм; детерминированность Хаффмана.
- Защитный охват: KODO round-trip через DPAPI, отсутствие исходного текста в сериализованной полезной нагрузке и отказ при изменении защищённого содержимого; формат почты и сложность пароля; ограничение восстановления десятью миллионами символов для декодеров Хаффмана, Шеннона–Фано и RLE; отклонение не-двоичных символов; KHF round-trip Unicode, двоичная упаковка, контрольная сумма и повреждённые/усечённые файлы; сериализация записи автосохранения, постановка конкурентной правки в очередь и повтор неуспешного сохранения.
- Проверка регрессии старта после авторизации: во время модального окна входа используется `OnExplicitShutdown`, а после успешного входа режим переключается на `OnMainWindowClose` только после назначения главного окна. Сборка Release подтверждена после этого изменения.
- Smoke-test опубликованного `KodosadStudio.exe` от 25.09.2026: окно входа открылось и оставалось доступным; форму закрыли без ввода или отправки учётных данных. Для запуска использовались отдельный LocalDB-экземпляр и временная база `KodosadStudioGuiSmoke`, созданная и удалённая в ходе проверки. Ручной вход в этом GUI smoke-test не выполнялся; проверка корректной аутентификации входит в SQL-интеграционные сценарии.
- Для r9 заново собран Release; шесть изолированных захватов включают вход, регистрацию, профиль, рабочее пространство, список запусков и архивный инспектор (`outputs/qa/kodosad-r9/`). В окнах регистрации и профиля видны правила пароля, рабочее место показывает дерево Хаффмана и метрики, архивный экран — зафиксированные исходник и поток.
- Рабочий экран r8 включает экспорт/импорт бинарного архива KHF; для дерева Хаффмана проверяются отображение кодов и обратное восстановление.

## SQL-интеграционные проверки

`KodosadStudio.IntegrationTests` проверяет свежую схему, обновление существующей схемы v1→v3, повторяемость миграций, регистрацию/вход, смену пароля, историю, изоляцию пользователей и шифрование снимков. Проверки v3 покрывают запрет сброса для старого неподтверждённого/неизвестного адреса, подтверждение только сохранённой почты после повторной проверки пароля, хранение хеша кода, отметку успешной отправки, минутный cooldown, срок 10 минут, пять ошибок, одноразовость и фактическую смену пароля. Прогон 02.10.2026 через LocalDB: **33/33 PASS**. Тест создал случайную базу `KodosadStudio_IT_*` и удалил её после завершения.

Сборка LocalDbFix разрешает имя экземпляра в актуальный именованный канал при каждом создании строки подключения. После этого исправления интеграционный прогон повторно прошёл: **33/33 PASS**; тестовая БД удалена.

Production `KodosadStudioDb` перед миграцией: версии 1,2; 5 пользователей, 7 проектов, 31 запуск. После миграции: версии 1,2,3; те же 5/7/31, все 5 прежних почт остались неподтверждёнными, таблицы кодов пусты, 2 новых FK и 4 CHECK доверенные, `DBCC CHECKCONSTRAINTS WITH ALL_CONSTRAINTS` без нарушений. Перед и после миграции сделаны `BACKUP DATABASE ... WITH COPY_ONLY, CHECKSUM` и `RESTORE VERIFYONLY ... WITH CHECKSUM`: `database-backups/KodosadStudioDb_pre-v3_2026-10-02_095335UTC.bak` и `database-backups/KodosadStudioDb_v3_2026-10-02_095402UTC.bak`. Живую SMTP-доставку не проверяли; она зависит от запущенного RouteStudio Mail API и его настроек.

Сборка `dotnet publish KodosadStudio/KodosadStudio.csproj -c Release -r win-x64 --self-contained true` завершилась без ошибок; актуальный EXE находится в `outputs/CourseworkBuilds/06-KodosadStudio-SqlServer-2026-10-02-LocalDbFix/`.
